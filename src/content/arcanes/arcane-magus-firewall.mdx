## Overview

Magus Firewall is a team-defense arcane that grants Void barrier absorption to nearby Warframes when Void Sling is cast. This arcane specializes in sustained damage mitigation through temporary shield absorption, complementing shield-focused Warframes and defensive squad builds.

## Effect

Each Void Sling cast creates a temporary void barrier on nearby Warframes, absorbing incoming damage. The absorption capacity scales from +25% of Warframe health at rank 0 to +125% at rank 5, persisting for 12 seconds. Multiple layers stack, enabling sustained barrier maintenance.

## Acquisition

Magus Firewall drops as an uncommon reward from Void Cascade missions on Zariman. Early progression unlocks access to this reliable defensive tool.

## Best on

Magus Firewall excels in shield-focused squad compositions:

- **Shield-tank Warframes** (Trinity, Hildryn, Gyre) scale absorption effectively.
- **Extended void cascades** — sustained barrier maintains protection through long runs.
- **Steel Path void fissures** — emergency absorption saves squads from lethal hits.

## Notes

Void barrier absorption is temporary and depletes when damaged. Reapplying Void Sling before expiration extends protection. The operator's own Warframe benefits from the barrier when nearby.
