## Overview

Arcane Cleanse Grineer is a faction-specific rare arcane providing status immunity against Grineer enemy types. This specialized arcane is essential for Grineer-heavy void cascades and Corpus/Grineer hybrid tileset farming.

## Effect

When fighting Grineer enemies, the Warframe has a 20% chance at rank 0, scaling to 100% (guaranteed) at rank 5, to automatically cleanse any negative status effect applied. At maximum rank, the Warframe maintains permanent status immunity against Grineer units.

## Acquisition

Arcane Cleanse Grineer drops as a rare reward from Zariman Void Cascade waves fighting Grineer enemies. Grineer-specific void cascade farming provides access.

## Best on

Arcane Cleanse Grineer is critical for Grineer-focused missions:

- **Grineer-heavy void cascades** — maintains status immunity throughout.
- **Steel Path Grineer missions** — cleanse corrosive procs enabling longer sustain.
- **Status-heavy builds** — eliminates status vulnerability for non-status-immune Warframes.

## Notes

The arcane only affects Grineer-applied status effects. Enemy Corpus procs are not cleansed. Factional farming requires careful enemy selection. Stacks with status-resistance mods.
