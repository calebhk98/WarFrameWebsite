## Overview

Bonewidow Engine is a Necramech component resource used to craft the Bonewidow, the melee-focused Necramech introduced with the Heart of Deimos update. According to WFCD, the description reads: "Engine component for the Bonewidow Necramech." Bonewidow is the defensive, melee-oriented Necramech variant, in contrast to the ranged combat Voidrig.

The Bonewidow Necramech is assembled from four components built in the Foundry: Capsule, Casing, Engine, and Weapon Pod. Each requires separate farming runs through Deimos content, specifically through Isolation Vaults and Cambion Drift open-world encounters. After assembly, the complete Necramech requires 72 hours of Foundry build time.

Deimos is the Infested moon of Mars, accessible after completing the Heart of Deimos quest. The Cambion Drift open world is populated by Infested fauna and Necramech enemies, making it the sole farming location for all Bonewidow components.

## Where it drops

Bonewidow Engine drops from hostile Necramech encounters on Deimos and from Isolation Vault bounty rewards. The Cambion Drift hosts free-roaming Necramechs as part of the open-world ecosystem; defeating these enemies drops Necramech components including the Engine. WFCD does not record a specific percentage drop rate for Bonewidow Engine, indicating it drops as a flat encounter reward rather than from a weighted loot table.

Isolation Vaults are multi-stage underground bounties accessed from Mother at the Necralisk hub. Tier 3 Isolation Vaults reliably spawn Necramech enemies in the vault interior, creating guaranteed opportunities for Bonewidow Engine drops. Completing all three tiers in a single run maximizes components per session.

## Used for

- Bonewidow Necramech full blueprint (requires Capsule, Casing, Engine, Weapon Pod)
- Entrati syndicate progression milestone (crafting Necramechs advances standing objectives)
- Deploying Bonewidow in Railjack Orphix survival missions once complete

## Tips

Run Tier 3 Isolation Vaults in a full squad for the most efficient Bonewidow Engine farming. Tier 3 vaults spawn the highest-level Necramech enemies, which have better component drop rates than lower-tier encounters. Completing all three vault tiers consecutively in one continuous run avoids re-entering the vault sequence from the Necralisk.

Cambion Drift Necramech roaming spawns provide supplemental Engine drops between vault runs. These open-world Necramechs spawn periodically across the drift map; scanning the area while completing other Deimos bounties doubles efficiency. All four Bonewidow components share the same drop routes, so a single farming session typically yields progress across all four components simultaneously.

## Notes

- Bonewidow Engine is non-tradeable between players.
- WFCD does not list a specific weighted drop percentage; farming the Cambion Drift and Isolation Vaults is the confirmed acquisition method per the Fandom wiki.
- All four Bonewidow components (Capsule, Casing, Engine, Weapon Pod) drop from the same locations; track all four simultaneously during farming sessions.
- Bonewidow and Voidrig components are not interchangeable; each Necramech requires its own set of four components.
- Heart of Deimos quest completion is required before accessing the Necralisk and Isolation Vault bounties.
